# FlowSync AI – SaaS Landing Page

A modern, responsive SaaS landing page for an AI-powered productivity and workflow automation platform.

## Features
- Responsive navigation bar
- Hero section with dashboard preview
- Six product feature cards
- How It Works section
- Starter and Professional pricing plans
- Contact form with input validation
- Responsive footer

## Technologies Used
- React.js
- Tailwind CSS
- JavaScript
- Vite
- Lucide React

## Installation

1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local URL provided by Vite.

## Production Build

```bash
npm run build
```
